# Shared-consciousness narrative

The optional fictional premise frames the Director as a shared consciousness and Sparks as distinct personalities. It does not describe a clinical condition or change identity, knowledge access, output schemas, moderation, scheduling, accounting or stored history. The Director guidance is included in fresh encounter context, including reused sessions; independent Sparks receive the premise in their own instructions and retain their existing holder-scoped context.

Default: disabled. After separate owner review and deployment, set LITTLE_SPARKS_SHARED_CONSCIOUSNESS_ENABLED=1 in the existing scheduler environment to enable; unset it or set 0 to roll back. Invalid values fail closed. No migration or hosted-agent edit is required. The hosted Director instructions remain authoritative and may conflict with this optional context; review them before activation. Prompt guidance cannot guarantee narrative behavior or prevent inference from supplied context. All accepted dialogue remains public.

Offline tests exercise both prompt paths, default and rollback behavior, and invalid configuration. No live evaluation is implied.
